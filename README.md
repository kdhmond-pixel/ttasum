# 따숨코치 앱

GitHub Pages에 올리면 핸드폰에 앱처럼 설치할 수 있어요. 설치한 뒤에는 인터넷 없이도 열려요.

## 이번 버전에서 바뀐 것
- **예시 버튼과 가상 학습 실험을 숨겼어요.** 실제로 쓰는 앱이에요.
- **학습 결과가 코칭과 알림에 합쳐졌어요.** ‘생활 기록’ 탭에서 나가요·왔어요를 14일 기록하면
  - ‘스마트폰 알림 일정’에 **내 기록으로 예측한 알림**이 나와요.
  - 귀가 전 알림 시점은 **강화학습**이 내 대답(켰어요·안 켰어요)으로 골라요.
  - AI 코칭이 생활 패턴, 예측 시각, 학습한 알림 시점까지 보고 코칭해요.
- **시연 모드**: 주소 끝에 `?demo`를 붙이면 예시 버튼·예시 기록·학습 실험(가상 사용자)이 보여요.
  예: `https://내아이디.github.io/ttasum/?demo` (멘토링·심사 때)

## 고친 내용 올리기 (업데이트)
1. GitHub 저장소 → **Add file → Upload files** → `index.html`, `sw.js`, `README.md`를 끌어다 놓기 (같은 이름이면 덮어써요)
2. 맨 아래 **Commit changes**
3. 1~2분 뒤 핸드폰에서 앱을 한 번 열었다 닫으면 새 버전으로 바뀌어요

## AI 키
앱의 ‘따숨 코치’ 칸 맨 아래 **🔑 AI 키**에서 Claude 또는 구글 Gemini를 고르고 키를 넣어요.
키는 그 핸드폰에만 저장돼요. **키를 index.html이나 GitHub에 절대 넣지 마세요.**

## 알아 둘 점
- 생활 기록·AI 키·입력값은 핸드폰 브라우저에만 저장되고 서버로 보내지 않아요 (AI 키를 넣으면 코칭할 때만 AI 회사에 전달).
- 처음 학습할 때(기록이 바뀔 때) 몇 초 걸릴 수 있어요.
